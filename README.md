# Free-commerce

MIT-licensed, TypeScript-only, opinionated commerce platform: headless backend, typed SDK, copy-in UI components and a merchant admin. One good default path beats many options.

Pre-alpha. Plan: [docs/execution-plan.md](docs/execution-plan.md). Contributing: [CONTRIBUTING.md](CONTRIBUTING.md).

```bash
pnpm install
pnpm build && pnpm typecheck && pnpm lint && pnpm test
```
