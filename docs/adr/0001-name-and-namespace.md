# Keep the working name "Free-commerce"; make renaming cheap

No short invented or metaphor-based candidate cleared GitHub, npm, domain and trademark checks together (availability was not verified end to end). We keep `Free-commerce` for development and hold the name in `brand.json` only, with a `pnpm rename` script (task 0.2a) and a CI check against hard-coded names.

## Consequences

- "Free" can read as "costs nothing" rather than freedom; accepted for now.
- Rename gate: the final name is confirmed with Jon before the first npm publish (task 5.8). Publishing a package name is hard to undo.
- Jon reserves the npm org, GitHub org and a domain when convenient and runs a real trademark search before 5.8.
